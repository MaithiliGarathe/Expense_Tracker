# 💰 Expense Tracker

A simple Python-based Expense Tracker that helps users record and manage their daily expenses.

The project was created to practice Python programming fundamentals and basic data handling.

## 🚀 Features

- ➕ Add new expenses
- 💵 Record expense amounts
- 📝 Store expense details
- 📊 Track total expenses
- 🔍 View recorded expenses
- 🖥️ Simple command-line interface

## 🛠️ Technologies Used

- Python
- Lists
- Dictionaries
- Functions
- Loops
- Conditional statements
- User input
